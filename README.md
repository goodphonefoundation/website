# The Good Phone Foundation Website

The official website for The Good Phone Foundation - helping people take back control of their digital lives.

## About

The Good Phone Foundation is dedicated to helping people see through manipulative systems in modern technology and build a healthier relationship with the digital world. We believe that technology should serve people, not trap them.

## Website Structure

This is a static website built with [Publii CMS](https://getpublii.com/). The site includes:

- **Who We Are** - Mission and vision of the foundation
- **What We Do** - Our programs and initiatives
- **Get Involved** - Ways to support and participate

## Deployment

The website is hosted on GitHub Pages and is accessible at:
- Primary: [goodphone.foundation](https://goodphone.foundation)

## Local Development

This is a static HTML site. To view locally:

1. Clone the repository
2. Open `index.html` in your browser, or
3. Use a local web server:
   ```bash
   # Python
   python -m http.server 8000
   
   # Node.js
   npx http-server
   ```
